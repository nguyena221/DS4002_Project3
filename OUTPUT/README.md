# Project outputs

`eda/` contains exploratory plots, name counts, statistics, and captions from
the complete raw archive. These are not adult-screened or modeling results.
The EDA script also generates a per-image brightness CSV locally; this is
excluded from Git because the aggregate outputs suffice for the repository.

`preprocessing_plan.md` records the agreed MI2 sequence and unresolved choices.
Add screening reports, final dataset counts, training summaries, and evaluation
figures here as they are produced. No final model results exist in this setup.
